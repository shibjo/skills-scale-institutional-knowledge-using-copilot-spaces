# OctoAcme Project Management Docs

This directory contains the core project management process documents used by OctoAcme to run work from idea to release and continuous improvement.

## Project management process overview

OctoAcme uses a lightweight, cross-functional project lifecycle built around clarity, ownership, and iterative delivery:

- Initiation: validate the business need, align stakeholders, define success metrics, and create a project one-pager.
- Planning: break work into backlog items, estimate scope, set milestones, and identify dependencies and risks.
- Execution: track progress through daily/weekly rhythms, keep work visible, and escalate blockers when needed.
- Risk and communication: track issues, communicate status, and make decisions through clear escalation paths.
- Release and deployment: confirm readiness, deploy with verification, and document rollback plans.
- Retrospective and improvement: capture learning, assign follow-up actions, and continuously improve the process.
